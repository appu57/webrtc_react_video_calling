WebRTC Real-Time Communication Project


Overview : This project implements WebRTC (Web Real-Time Communication) to facilitate peer-to-peer audio, video, and data sharing in web applications. With WebRTC, you can establish direct communication between browsers without the need for third-party plugins or external software.
This application can be used for various real-time communication solutions like:
       a. Video calls
       b. Voice calls
       
Features:
a. Peer-to-Peer Communication: Enable direct audio, video, and data communication between browsers.
b. Real-time Media Streaming: Audio and video streaming between peers with low latency.
c. Signaling Server: Simple signaling server implementation using WebSocket to exchange session data.


Technologies Used

WebRTC: For peer-to-peer data and media streaming.
Node.js: For server-side logic and signaling server.
Express.js: For serving the web app and handling HTTP requests.
Socket.io: For real-time signaling between peers.
HTML5 & CSS3: For frontend user interface.
JavaScript (ES6+): For client-side scripting.
Bootstrap: For responsive, mobile-first front-end design.
